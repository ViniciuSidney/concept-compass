# Revisão documental final

A documentação oficial está no Google Drive, nos documentos 01 a 12.

Decisões que orientam esta pasta:

- hierarquia exclusiva: Matéria → Tema → Assunto;
- quatro áreas globais: Visão Geral, Matérias, Pesquisa Geral e Configurações;
- aplicação estática com HTML, CSS e JavaScript nativos;
- módulos ES e hash routing;
- zero dependências de execução;
- armazenamento local encapsulado;
- `viewMode` reservado como `cards`, sem seletor na v0.1;
- service worker não registrado no M0;
- nenhuma funcionalidade acadêmica implementada antes do M1/M2.
