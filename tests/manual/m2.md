# Roteiro manual — M2

O M2 não possui CRUD visual. Seu objetivo é validar a camada de domínio e persistência antes que a interface possa alterar dados acadêmicos.

## Comandos e regressão

- **M2-T01:** executar `npm test` e confirmar todos os testes aprovados;
- **M2-T02:** executar `npm run lint` e confirmar ausência de erros;
- **M2-T03:** executar `npm run format:check` e confirmar a formatação;
- **M2-T04:** executar `npm run verify:m2` e confirmar as quatro mensagens de sucesso;
- **M2-T05:** executar `npm run check` e confirmar o portão completo;
- **M2-T06:** executar `npm run serve` e confirmar que o AppShell do M1 continua abrindo;
- **M2-T07:** repetir a navegação pelas quatro áreas e confirmar ausência de regressão;
- **M2-T08:** confirmar que ainda não existe CRUD visual ou dado acadêmico real na aplicação;
- **M2-T09:** confirmar ausência de erros no console durante a regressão visual;
- **M2-T10:** executar `git status` e confirmar a árvore de trabalho limpa.

## Aprovação

O M2 será aprovado quando M2-T01 a M2-T10 estiverem OK. Os cenários de validação, integridade, falha de gravação, corrupção e migração são cobertos prioritariamente pelos testes automatizados.
