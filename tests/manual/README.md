# Testes manuais

Os roteiros detalhados serão adicionados conforme os marcos do documento 11.

No M0, verificar apenas:

1. `npm install` conclui sem erro;
2. `npm run check` passa;
3. `npm run serve` abre a página mínima;
4. não existem dependências de execução;
5. nenhum dado acadêmico real está no projeto.
